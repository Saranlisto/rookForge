# Day 018 - Alpha-Beta and Quiescence Search

## Summary

Upgraded the first fixed-depth search into an alpha-beta search with terminal-state handling, basic tactical move ordering, and a bounded quiescence search at leaf nodes.

This is the logical next milestone after Day 017. The external plan numbering may differ, but the implementation keeps the repository history sequential and coherent.

## Search Score Convention

Search scores are reported from the root side-to-move perspective.

```text
Positive score = better for the side to move at the root
Negative score = worse for the side to move at the root
```

The static evaluator remains white-positive. Search converts that value with `evaluate_for_side_to_move`.

Checkmate uses a large centipawn-style score:

```text
MATE_SCORE = 100000
```

Mate scores are adjusted by ply so faster mates are preferred and slower losses are delayed.

## Implemented

- Alpha-beta pruning for fixed-depth search.
- Checkmate and stalemate detection at terminal nodes.
- `SearchOutcome` metadata for best move, checkmate, and stalemate.
- `SearchKind` metadata for alpha-beta versus alpha-beta plus quiescence.
- Basic tactical move ordering.
- Capture and promotion quiescence search.
- Stand-pat evaluation in quiescence.
- Bounded quiescence depth guard.
- Quiescence node counting.
- Search elapsed time and nodes-per-second reporting.
- `--no-quiescence` CLI flag for comparison/debugging.

## CLI Usage

```bash
rookforge search --fen startpos --depth 3
rookforge search --fen startpos --depth 3 --no-quiescence
```

Example output now includes:

```text
nodes: <searched nodes>
qnodes: <quiescence nodes>
elapsed_ms: <elapsed milliseconds>
nodes_per_second: <nodes per second>
outcome: bestmove
search: alpha-beta+quiescence
```

Exact node counts, timings, and best moves may change as move ordering and evaluation evolve.

## Tests Added

- Alpha-beta returns a legal move from the starting position.
- Search still captures hanging material.
- Search still prefers queen promotion where material makes it best.
- Checkmate detection uses legal moves and check state.
- Stalemate detection uses legal moves and check state.
- Search reports checkmate and stalemate outcomes gracefully.
- Mate scores outrank material scores.
- Quiescence returns static evaluation when there are no tactical moves.
- Quiescence considers an obvious winning capture.
- Quiescence tactical move filtering excludes quiet moves.
- Quiescence tactical move filtering includes promotions.
- Quiescence respects the depth guard.
- `--no-quiescence` reports the alpha-beta-only search kind.
