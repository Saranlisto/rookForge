# Day 019 - CLI and Release Polish

## Summary

Polished the current public CLI surface and added a repeatable release-build command.

This maps to the external "Day 32" CLI/release polish prompt, but the repo history remains sequential because the engine is currently complete through local Day 018.

## Implemented

- Consistent help sections for current commands.
- Main help text with version, command list, options, and examples.
- Cleaner stderr errors for invalid FEN, move, square, color, and depth input.
- A conservative CLI depth guard for current debug commands.
- Stable JSON output for `rookforge search`.
- JSON escaping helper for automation-safe output.
- `make release` for optimized local builds.
- Search JSON smoke command in `make check`.

## CLI Usage

Current text output:

```bash
rookforge search --fen startpos --depth 3
```

Automation-friendly JSON output:

```bash
rookforge search --fen startpos --depth 0 --json
```

Release build:

```bash
make release
./target/release/rookforge --version
```

## Tests Added

- Command help outputs include consistent `USAGE` and `STATUS` sections.
- Invalid FEN returns a clean error with a FEN hint.
- Invalid move returns a clean error with a UCI move hint.
- Invalid search depth returns a clean error.
- Depth above the current CLI limit is rejected.
- `search --json` emits the expected stable shape.
- JSON string escaping handles quotes, backslashes, and control characters.
- Process-level CLI tests verify invalid FEN/move/depth fail on stderr without panics.

## Local Checks

The standard validation workflow remains:

```bash
make check
```

It now includes:

```bash
cargo run -- search --fen startpos --depth 0 --json
```
