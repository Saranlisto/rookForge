# Day 015 - Perft Validation Suite

## Summary

Added a stronger perft validation layer and a repeatable divide workflow for debugging legal move generation.

## Implemented

- `perft_divide` in `rookforge-core` for root-move node counts.
- `rookforge perft --fen <FEN|startpos> --depth <DEPTH> --divide`.
- Timing and nodes-per-second fields for normal perft output.
- Timing and nodes-per-second fields for divide output.
- `make perft` for deeper reference checks that are useful before touching move generation.
