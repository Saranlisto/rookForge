# Day 016 - Material Evaluation

## Summary

Added the first static evaluation function: material only, independent of side to move.

## Score Convention

```text
Positive score = better for White
Negative score = better for Black
Zero = equal material
```

Scores use centipawn-style integer values.

## Material Values

| Piece | Value |
| --- | ---: |
| Pawn | 100 |
| Knight | 320 |
| Bishop | 330 |
| Rook | 500 |
| Queen | 900 |
| King | 0 |

## Implemented

- `evaluate(&Position) -> i32`
- `material_value(PieceKind) -> i32`
- Public material constants for each piece kind
- CLI debug command:

```bash
rookforge eval --fen startpos
rookforge eval --fen "8/8/8/8/8/8/4P3/4K2k w - - 0 1"
```

Example output:

```text
fen: startpos
score_cp: 0
perspective: white-positive
```

## Tests Added

- Starting position evaluates to 0.
- Empty board evaluates to 0.
- White extra pawn evaluates to +100.
- Black extra pawn evaluates to -100.
- White extra knight evaluates to +320.
- Black extra bishop evaluates to -330.
- White extra rook evaluates to +500.
- Black extra queen evaluates to -900.
- Mixed material evaluates correctly.
- Promotion impact is reflected after applying a promotion move.
- CLI eval smoke tests for `startpos` and a white extra pawn.

## Local Checks

The standard validation workflow now includes eval smoke commands:
