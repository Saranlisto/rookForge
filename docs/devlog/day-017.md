# Day 017 - Fixed-Depth Negamax Search

## Summary

Added the first basic search: plain fixed-depth negamax over legal moves.

## Search Score Convention

Search scores are reported from the root side-to-move perspective.

```text
Positive score = better for the side to move at the root
Negative score = worse for the side to move at the root
```

The underlying static evaluator remains white-positive. Search converts that score with `evaluate_for_side_to_move`.

## Implemented

- `SearchResult`
- `evaluate_for_side_to_move(&Position) -> i32`
- `search_best_move(&Position, depth: u32) -> SearchResult`
- Plain recursive negamax
- Legal-move-only root search
- Best-move selection
- Graceful `best_move: None` result when no legal move is available
- CLI debug command:

```bash
rookforge search --fen startpos --depth 1
rookforge search --fen startpos --depth 2
```

Example output:

```text
fen: startpos
depth: 1
best_move: a2a3
score_cp: 0
nodes: 20
```

The exact best move from equal-material positions can change with move ordering.

## Tests Added

- Depth 0 returns static side-to-move evaluation.
- Side-to-move evaluation flips a white-positive score for Black.
- Depth 1 returns a legal move from the starting position.
- Search result move is legal.
- Search captures hanging material.
- Search prefers queen promotion when material makes it best.
- Empty/no-legal-move position returns no best move gracefully.
- Node count is greater than zero for normal positions.
- CLI search smoke tests for depth 1 and depth 2.
